## Problem

The TUI is a good browser and the wrong place to be if you are already in an editor.

## Proposal

A thin client over the JSON output or the MCP server — deliberately thin, because
maintaining editor plugins is a larger commitment than this project makes.

## Acceptance criteria

- [ ] Decide which single editor, if any, is worth supporting.
- [ ] If one is, decompose with a milestone.
