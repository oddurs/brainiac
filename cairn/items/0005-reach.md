## Ships

Handle the repositories you actually have — monorepos, more languages, prose with structure, files too big for the cap — and stay fast doing it.

Everything here is a quality change, so everything here is judged by the harness from
v0.2. An item that cannot show a score is not done.

## Done when

- [ ] A monorepo can be indexed once and queried per package.
- [ ] Java, C, C++ and Ruby have symbol graphs, each verified on a real repository.
- [ ] Markdown is chunked by heading rather than by sliding window, and it scores better.
- [ ] Files over the size cap are chunked instead of silently skipped.
- [ ] Cross-file import resolution improves graph edges, measurably.

## Explicitly not in this milestone

- API stability. Surfaces can still move until v1.0.
- Windows.
